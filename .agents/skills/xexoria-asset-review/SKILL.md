# xexoria-asset-review

Use original or commercially compatible licensed assets and retain source URL/licence/attribution. Inspect real mesh files, not concept labels. Check metre scale, pivot, bounds, normals, UV seams, texel density, materials, skeleton weights and animation clips. Count triangles per LOD, visible draw calls and texture GPU memory; compressed download size is different. Use instances and LOD where appropriate. Verify glTF export in Babylon; Blender procedural materials do not automatically transfer. Compare silhouettes, construction detail, palette and lighting at the 13 m game camera. Use Blender only after checking it exists. Preserve raw originals; do not overwrite approved assets or claim a generated mesh is game-ready without checks.
