# xexoria-cloud-check

Read manifests, lockfiles, toolchain pins and AGENTS.md. Run python3 scripts/cloud_setup.py in check-only mode first. Never infer an empty repo is a new game request. Before installation inspect dependency scripts and use the exact pinned tool versions. Preserve source history, imported assets and existing instructions. Record build/test commands and real results. No secrets, deployment or credentials changes.
