# xexoria-gameplay-qa

Test visible guest/login states and loading failures. Compare player position before movement, during movement and after release. Cover WASD, touch joystick, pointercancel, blur, visibility change, diagonal speed, click-to-move pathfinding and UI taps not moving the player. Test camera collision and UI resize/safe areas. Verify attack cooldown, authoritative damage, single reward per defeat, level/stat allocation, death/respawn and reconnect. Verify master mute including already playing loops. Record actual device/browser and backend; no mobile or multiplayer claims from one browser. Capture failures with reproducible steps.
